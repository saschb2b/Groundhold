# Release notes

Each release's own page, newest first: what changed, as a player reads it, with pictures from the game. The GitHub
release opens with its page and adds the downloads (`tools/release/release_notes.py`); a release without a page shows
its [CHANGELOG](../../CHANGELOG.md) section instead, which keeps every detail. How a page and its pictures are made is
[the release skill](../../.claude/skills/release/SKILL.md).
