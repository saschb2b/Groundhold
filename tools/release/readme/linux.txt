Groundhold $version for Linux (x86_64)
======================================

A co-op tower defense for one to four players. MIT License, by Sascha Becker.
Source, changes and help: https://github.com/saschb2b/Groundhold


Start it
--------

Unpack groundhold-linux-x64.tar.gz anywhere and run groundhold in its Groundhold folder
(double-click it, or from a terminal):

    cd Groundhold
    ./groundhold

./install.sh adds Groundhold to your desktop's application menu with its icon, pointing at
this folder (run it again after moving the folder); ./install.sh --remove takes the entry
and the icons away again.

The same release page has the game two more ways: groundhold-x86_64.AppImage, one file to
make executable and run (chmod +x groundhold-x86_64.AppImage), which AppImageUpdate and
Gear Lever keep up to date; and groundhold_amd64.deb for Debian, Ubuntu and their kin
(sudo apt install ./groundhold_amd64.deb), which puts it in the application menu and on
the path as groundhold.

It needs a graphics driver with Vulkan; with an older one, start it as

    ./groundhold --rendering-driver opengl3

Your name, Builders and settings live in ~/.local/share/godot/app_userdata/Groundhold/.


Play together
-------------

Online: open Join (J) and press Go on the Official row
(wss://groundhold.saschb2b.com/causeway), or type a friend's party code. Friends in the
browser play at https://saschb2b.github.io/Groundhold/play/ and join the same parties.
The official server's rules, and what it keeps and for how long:
https://saschb2b.github.io/Groundhold/policy.html

On your network: one computer runs the server, groundhold-server, from the same release
page: groundhold-server-linux-x64.zip (groundhold-server-linux-arm64.zip on ARM64), or
groundhold-server-python.zip with Python 3.11 or newer. Its window prints the address to
type; the game lists it under Join, Nearby. The others join with the code on your strip. A
firewall must let TCP port 8766 in, and UDP port 8767 for Nearby.
